# Modern CSS Techniques

CSS has evolved significantly in recent years. Let's explore the latest features that will transform how you style web applications.

## Container Queries

Container queries are revolutionary because they allow components to respond to their container's size, not just the viewport:

```css
.card-container {
  container-type: inline-size;
}

@container (min-width: 400px) {
  .card {
    display: grid;
    grid-template-columns: 1fr 2fr;
  }
}
```

This enables truly modular, responsive components.

## Cascade Layers

Cascade layers give you fine-grained control over CSS specificity:

```css
@layer reset, base, components, utilities;

@layer reset {
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
}

@layer components {
  .btn {
    padding: 0.75rem 1.5rem;
    border-radius: 0.5rem;
  }
}
```

## CSS Nesting

Native nesting is now supported in all major browsers:

```css
.card {
  background: white;
  border-radius: 0.5rem;
  
  &:hover {
    transform: translateY(-4px);
    box-shadow: 0 10px 40px rgba(0, 0, 0, 0.1);
  }
  
  &__title {
    font-size: 1.25rem;
    font-weight: 600;
  }
}
```

## Modern Color Functions

CSS now supports powerful color manipulation:

```css
.element {
  /* Using relative color syntax */
  background: oklch(from blue 70% chroma 30%);
  
  /* Color mixing */
  background: color-mix(in srgb, #ff0000, #0000ff);
  
  /* Contrast function */
  color: contrast-color(#000000, white, black);
}
```

## Scroll-Driven Animations

Create animations tied to scroll position without JavaScript:

```css
@keyframes reveal {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.reveal {
  animation: reveal linear both;
  animation-timeline: view();
  animation-range: entry 0% cover 40%;
}
```

## Conclusion

These modern CSS features enable you to build more maintainable, flexible, and beautiful interfaces. Start incorporating them into your projects today!
